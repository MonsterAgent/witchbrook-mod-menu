## 🧩 About

**Witchbrook helpers** is a curated list of Witchbrook open-source tools:

- **Overlays** — on-screen helpers, layout notes, inventory viewer, day-cycle tracker
- **Quality-of-Life Helpers** — recipe catalog, crop planner, overlay notes
- **Research Notes** — spell layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Day Cycle Tracker — monitor in-game time and seasons
- Inventory Viewer — inspect bag contents at a glance
- Recipe Catalog — browse known crafting recipes
- Movement Notes — study pathing around town (educational)

### 🎨 Catalog & Cosmetics
- Item Catalog — browse items, seeds, and tools
- Custom Outfit Notes — organize character cosmetics
- Crop Planner — plan garden layouts for study

### 🏋️ Practice Layout
- Save Layout Notes — organize save spots for review
- Relationship Tracker — log NPC interactions for study
- Quest Notes — chain events in the journal for reference
